# バンジーガムのキャラクター動作素材

## 素材と再生設定

全ガム動作は帽子姿の菜月さんの右向き透過スプライト。各1024 × 512 px、4列2行、1コマ256 × 256 px、左上から行順の8コマ。

|動作|シート（images/normalized/）|Godotアニメーション|推奨再生|
|---|---|---|---|
|発射|natsuki_gum_fire.png|gum_fire|12 fps・1回|
|引っ張られる|natsuki_gum_pull.png|gum_pull|8 fps・ループ|
|ぶら下がる（真上）|natsuki_gum_hang.png|gum_hang|8 fps・ループ|
|ぶら下がる（方向中割り）|natsuki_gum_hang_angles.png|gum_hang_angles|角度で選択・停止保持|

Godot用コピーと設定済み `SpriteFrames` は `natsuki2027/assets/characters/natsuki/` に置く。`gum_animations.tres` を `AnimatedSprite2D.sprite_frames` に割り当ててプレビューできる。プレイヤーは起動時に既存の待機・走り・ジャンプのSpriteFramesへガム動作を統合する。

## 表現と今後の接続方針

- 発射：前方へ手を出して照準姿勢へ移る。生成結果は最初から腕が前方に出ており、大きな振りかぶりはない。飛行中は発射姿勢を使い、移動区間レイで先端の到達を判定する。接着したら再生終了を待たず接着姿勢へ移る。
- 引っ張られる：斜め上へ伸ばした腕に対して、脚と髪が後方へ流れる空中姿勢。
- ぶら下がる：片手を頭上へ伸ばし、肩で荷重を受け、膝を曲げた姿勢。
- 腕の向きは発射方向／最初の支持点への方向で選ぶ。発射中は地上／空中を問わず方向姿勢を優先。接続中は空中かつ張力10超で方向姿勢を使う。上方かつ真上基準70度未満は上げた腕、70度以上（上半分では水平から20度以内）は発射 `gum_fire`／接続 `gum_pull`。速度や支持点までの高さは腕方向の条件にしない。接続中の接地／弛緩時・回収中は通常の移動／空中姿勢。下方向は既存fire/pull素材を使い、上方素材を流用しない。
- キャラクターの移動・振り子・加速は物理処理が決定する。アニメーションによる移動や速度上書きは行わない。解除後は既存の空中動作へ戻し運動量を保持する。
- ガム線と付着エフェクトは別描画。各コマの手先を目視で採取した描画用座標は `player.gd` の `GUM_HANDS` に保持する。通常動作中は胸付近を描画起点とする。物理接続点と見た目の手先を混同しない。
- 左向きは水平反転を想定。ぶら下がりの上方接続は追加の8方向差分へ切り替える。腕の分離や下方接続の方向差分は未実装。全身を回転して接地姿勢を壊さない。

## 制作・検証

全ガム素材は菜月さんの青い髪・白いつば広帽子／濃紺帯・白いワンピースと靴を共通使用し、全ガム動作で左奥手をガムへ伸ばし、右手前で帽子を押さえる。組み込みimagegenの原本は `images/gum-source/`、実使用は `images/normalized/` とruntimeの同一コピー。

通常牽引 `natsuki_gum_pull.png` と真上 `natsuki_gum_hang.png` は時間差分8コマ。角度別原本 `natsuki_gum_hang_inbetweens.png` は真上基準10/20/30/40/50/60/70/80度を目標にした方向差分であり、時間ループではない。生成角度の実測保証はない。3原本とも1774×887 RGBA、各セルを共通244×244へnearest変換、alpha128閾値、256pxセルの(6,18)へ配置、不可視RGBを黒へ整理する。全身はセル内に収める。

プロンプトは `specs/natsuki-pull-image-prompt.txt`、`specs/natsuki-hang-image-prompt.txt`、`specs/natsuki-hang-angles-image-prompt.txt`。手元座標は `player.gd` の `GUM_HANDS` に従う。通常牽引は(199,111)、真上は(157,62)、角度別は(170,50)/(176,55)/(185,66)/(192,79)/(194,89)/(199,99)/(201,109)/(202,121)。いずれも左奥手の描画位置で、物理接続は胸のまま。

### 実行時の方向選択

- `images/normalized/natsuki_gum_hang_angles.png` と同一のGodotコピーを使用。1024×512px、256pxセルの4列2行。原本セルを最近傍で244pxへ揃え、各セル(6,18)に配置、α128未満の抽出残留を透明化。身体と足元を既存hangに近づけた共通倍率・共通オフセットで、ポーズ別の拡大縮小はしない。
- `gum_animations.tres` の `gum_hang_angles` は方向順8コマ。実行時の上方セクターは真上基準70度未満、発射中または空中・張力10超の接続中に使う。70度以上は横寄り／下方のfire/pullを使うため、80度コマは現在選ばない。
- 接続中は `support_point() - origin()`、発射中は `shot_direction` を真上基準で評価する。発射初期の先端が胸と同位置でも方向を失わない。上方セクター内で5度未満は既存 `gum_hang` をループ、それ以外は最寄りの方向コマを停止保持する。同距離は小さい角度側。5度・70度境界と最寄り判定には0.0001度の浮動小数誤差許容を適用。左は水平反転、巻き付きは最終接着点ではなく最初の支持点を向く。
- 高速でも上方セクターでは腕を上げる。発射／接続で共通の方向選択を使い、手元側は連続追従する。物理処理・キャラクター本体・当たり判定は変更しない。
- 手先座標は `player.gd` の `GUM_HANDS.gum_hang_angles` にセル座標で保持し、反転・描画変形を反映した追従目標として使用する。線の起点は下記の連続追従で更新する。
- `tools/verify_hanging_poses.gd` は左右・発射／接続・速度0/150/500・支持点距離2/400pxを組み合わせ、真上基準0〜180度を0.25度刻みで17,304ケース検証する。上方角度コマ、水平から20度境界、下方の既存姿勢、短距離／高速、発射直後、巻き付き、手先、弛緩、物理形状不変も確認する。

方向選択の調査は共有設定 `Hanging Pose Diagnostics` を使用する。実角度・選択コマ・公称角度・差・姿勢条件をログへ記録する。`angle_source` は発射時shot／接続時support、`upper_sector` は腕上げセクターかを示す。詳細は `game-settings.md`。検証ツールはログの有効化／抑制／退出も確認する。

### 手元側の連続描画起点

`gum_visual_target()` はポーズごとの手先座標、`gum_visual_origin()` は線が実際に使う連続追従座標。Playerローカル座標のオフセットを各物理ティックに1回、アニメーションと描画変形の更新後、`Gum Hand Follow Speed`（360px/s、60Hzで最大6px/step）で目標へ近づける。前方→頭上、角度コマ切り替え、左右反転で線の起点が即座に飛ぶことを防ぐ。生成画像の腕のポーズ自体は方向別コマのままなので、切り替え直後の短い間は線の起点が描画された手へ追いつく途中になる。

オフセットをPlayerローカル座標で保持するため、キャラクターの実際の移動には即座に追従する。描画中の読み取りで状態を進めず、待機中も更新し、food回収ロック中も同じ更新を行う。起動時は現在の目標で初期化する。物理接続点は胸のまま、張力・経路・力・衝突は変更しない。

`verify_gum_hand_origin.gd` は30/60/120Hz相当の前方／頭上／牽引／方向コマ／通常姿勢と左右反転で位置飛びなし・速度上限・収束、移動の即追従、描画変形、物理不変、通常／foodロックの実simulate更新を確認する。

## 大きな髪の遅れを伴う追加パターン

`images/gum-source/natsuki_gum_hair_followthrough.png` は菜月さんの1774×887透過RGBA、4×2・8コマの時間差分。左奥手を右上へ伸ばし、右手前は白い帽子を軽く押さえる。青いポニーテール、濃紺の帽子リボンと白いスカートが、通常→後方へ大きくなびく→下へ曲がる→戻りの順で遅れて動く。体格・腕の位置はほぼ固定し、腰の大きな折れや回転は入れない。

組み込みimagegenで生成・透明縁修正。プロンプトは `specs/natsuki-hair-followthrough-image-prompt.txt`。既存の共通244px変換・オフセット(6,18)で正規化し、透明画素のRGBを黒へ整理して表示時の色残留を防ぐ。ガム線・効果・床・文字は含めない。

### 強い横牽引での実行時選択

`tools/build_gum_hair_art.py` が全コマ共通244×244pxの最近傍変換、オフセット(6,18)、アルファ128での抽出を行い、正規化／Godot側へ同一1024×512pxシートを出力する。`gum_hair_pull` は8コマ10fpsの時間ループ。既存の方向差分と全素材は保持する。

空中かつATTACHEDの通常ガム接続で、実際の `player_force` の水平成分絶対値が `Gum Pull Pose / Gum Hair Pull Force`（初期700）以上、かつ水平成分が垂直成分以上で上向きまたは水平のときに選ぶ。速度だけでは選ばない。継続中は開始しきい値の75%（初期525）まで保持して境界での点滅を抑える。弱い力、真上・下向き、接地、発射／回収では従来の姿勢選択へ戻る。左右は支持点方向で反転する。空中ジャンプ回転・梯子等の既存優先順位は維持する。

手元は0-based3/7コマを(217,100)、他を(199,100)として共通連続追従へ渡す。物理接続点・カプセル・力・運動量は変更しない。`tools/verify_hair_pull.gd` は開始／維持／終了、左右、垂直／下向き／飛行除外、カスタムしきい値、時間コマ進行と物理形状不変を確認する。

## 菜月さんの発射モーション

`images/gum-source/natsuki_gum_fire.png` は菜月さんの生成元（1774×887 RGBA）。左奥手の開いた掌で前方へ発射し、右手前で白いつば広帽子を軽く押さえる8コマ。青いポニーテール、濃紺の帽子帯、白いワンピース・靴を承認済み正面絵に合わせる。待機とは異なり、全コマで帽子を押さえる。

実使用は `images/normalized/natsuki_gum_fire.png` と同一の `natsuki2027/assets/characters/natsuki/natsuki_gum_fire.png`。1024×512／256pxセル／4×2、8コマ12fps・非ループ。全セル共通53.40599%最近傍縮小、alpha50%閾値、共通Xオフセット10px、Yは上段15px／下段14pxで下端y232に揃える。個別の体格調整はしない。`player.gd` の `GUM_HANDS.gum_fire` は新しい発射側の掌へ更新。左向きは既存の水平反転で描画し、左右別シートは作らない。物理接続点・発射方向選択は変更しない。上方発射が使うhang系素材も菜月さんで統一する。

組み込みimagegen使用。完全な生成プロンプトは `specs/natsuki-fire-image-prompt.txt`。

## 真上ぶら下がりの腕配置

`natsuki_gum_hang.png` は角度別シートの腕の前後関係を基準とし、左腕を真上へ伸ばし、右手で帽子の側面を押さえる。上げる腕が頭頂部から生えて見えないよう、奥肩へつなぎ、帽子を押さえる手前腕と分離する。8コマの微小な脚・髪・裾の揺れは維持。原本と正規化／runtimeを同時更新し、描画手元は全8コマ(157,62)。上げた左手は角度別元画像の最初の姿勢を基準に、指先が帽子の頭頂より少し上（原本約10〜15px）に収まる長さ。最新編集プロンプトは `specs/natsuki-hang-arm-length-prompt.txt`。既存244px変換・(6,18)配置・8fps、物理／方向選択は変更しない。

## 発射・通常牽引・髪なびきの腕統一

角度別シートを基準に、3シートとも左奥手ガム／右手前帽子へ肩と上腕の重なりを整理する。全身AnimatedSprite2Dのコマで描き、手や腕の独立描画は行わない。最新編集プロンプトは `specs/natsuki-gum-{fire,pull,hair}-arm-unification-prompt.txt`。fireは既存共通53.40599%・X10/Y15/14、pull/hairは244px共通変換+(6,18)。alpha128で整形し不可視RGBを黒へ整理。物理・方向選択・線起点の連続追従は維持。
