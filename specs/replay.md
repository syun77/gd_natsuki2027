# リプレイ

リプレイ機能は `scripts/replay_store.gd` の `ENABLED = false` により無効化している。

- タイトルの「RELAY再生」とポーズメニューの「リプレイ再生」はグレーアウトし、マウス／キーボード／ゲームパッドから選択できない。
- 保存済みデータがあっても再生は許可しない。再生要求を直接呼んでもシーン遷移しない。
- 起動時に保存ファイルを読み込まず、読み込みThreadも開始しない。
- 描画状態・入力・効果音のリプレイ記録を行わない。固定更新の記録コールバックは停止する。
- クリア・死亡復帰・手動リトライでもリプレイファイルを新規作成／上書きしない。一時保存ファイルも作らない。
- 既存の `user://latest_replay.dat` は削除しない。
- `scenes/replay.tscn` を直接実行した場合もタイトルへ戻る。

START、ゲーム操作、クリア結果、得点、残機、通常のベストタイム保存は利用できる。入力のみを保存する方式への切替は行っていない。

再生シーンと描画スナップショット実装はコード内に保持するが、公開入口は同じgateで停止する。診断用の形式検証・描画収集helperを直接呼ぶことは可能で、通常ゲームからの記録には使わない。無効化のために保存形式や既存データを変換しない。

## 検証

`tools/verify_replay.gd` は無効化時に、起動loader／記録callback停止、既存データを読まないこと、タイトル／ポーズの再生無効、直接signalやシーン起動からの再生禁止、クリア／リトライ後の記録なし、既存保存bytes不変と新規保存なしを確認する。試験保存先は/tmpで通常データを変更しない。

`verify_time_attack.gd` と `verify_pause_menu.gd` はゲーム開始、クリア結果、通常ポーズ操作を回帰確認する。`verify_lives.gd` は死亡／残機処理を確認する。

容量分析は [replay-size-analysis.md](replay-size-analysis.md)、入力方式の実験結果は [input-only-replay-verification.md](input-only-replay-verification.md) を参照。
